# Marketland Auto Parts

Build a responsive e-commerce app called Marketland Global for selling auto spare parts.

The app should work smoothly on Android, iOS, and web browsers (including Google Chrome) and be designed so it can later be packaged and published on the Google Play Store.

Customer Features

Customers can register/login and edit their own account details.

Browse auto spare parts with pictures, product names, descriptions, prices, and availability.

Search and filter products.

View product details.

Add products to cart and place orders.

Checkout/order form with customer name, phone number, delivery address, and order summary.

Show my current payment/account details during checkout.

Customers can view their order status.

Customer service section with phone number and email.

Admin Features

The first registered account should become the Admin account and have an Admin option inside the three-dot menu.

Only the Admin should be able to access the Admin Panel.

From the Admin Panel, I must be able to add, edit, and delete:

Product pictures

Product names

Product descriptions

Product prices

Product availability

Payment/account number and bank details

Customer service phone number

Customer service email

Store information

I should be able to change these details anytime without rebuilding the app.

Design

Make it modern, clean, professional, and similar to a normal shopping app, but do not copy Jumia's branding or design.

Use the name Marketland Global throughout the app and make the interface easy for Nigerian customers to use.

Make the website/app responsive so the same project works properly on mobile, tablet, and desktop.

Most importantly, create the database and authentication properly so that products, customer accounts, orders, and my admin changes are saved permanently.
